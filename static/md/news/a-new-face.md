# A new face, built in the open

> The Future has a new look: the same design system as the Swiss chapter, a wireframe globe as the international mark, no trackers, and all source code public on GitHub.

Source: https://the-future.world/news/a-new-face/

As of today, the website of The Future has a new look. It is meant to say more clearly what we stand for: artificial intelligence and robotics can create prosperity for everyone, if someone builds the plan for it. The website should be able to show that plan in three seconds and explain it in three hours.

---

## One design system, two marks

The Future shares its design system with its Swiss chapter, [Die Zukunft](https://die-zukunft.ch). The website was meant to feel futuristic, but not kitschy: no neon colours, no robot eyes. Instead, things you can touch: a light ground like ceramic, dark ink, fine lines as on a construction drawing.

The colour is **Alpenglühen** (alpenglow): pink, magenta, violet and indigo, like mountains in the first light of day. It stands for optimism without pathos.

Each site has its own mark. The Swiss chapter uses the cube cross, a Swiss cross made of seven cubes. The international movement uses a **wireframe globe with continent outlines**: drawn in the same fine lines, for a movement that is not bound to one country.

---

## The manifesto, with permanent addresses

The [manifesto](https://the-future.world/manifesto/) now consists of ten theses, adapted from the Swiss manifesto for any country or city. Every section has an address in the corner, for example 0x1002 for the first thesis. The addresses are the same on both sites, so a thesis can be linked and quoted in the same way wherever it appears.

---

## Built in the open

The addresses give away how we work: like an open software project. The source code of this website is public on [GitHub](https://github.com/zukunft-ch/the-future.world). It runs without trackers.

If you find a mistake or have a better wording, you can contribute directly, with an issue or a pull request. A movement that calls for open government should work openly itself.

The future is a construction project. So is this website. [Build it with us.](https://the-future.world/join/)
